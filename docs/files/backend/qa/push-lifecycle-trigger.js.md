# push-lifecycle-trigger.js

Source: [backend/qa/push-lifecycle-trigger.js](../../../../backend/qa/push-lifecycle-trigger.js)

Captures a disposable push-test bridge and sends only its prepared synthetic messages; its temporary file contains test credentials.

See [Tests](../../../../docs/TESTING.md) before running it. Hosted Live tests need an explicitly chosen disposable service; local tests must not use an installation containing wanted accounts.
