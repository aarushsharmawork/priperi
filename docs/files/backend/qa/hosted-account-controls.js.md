# hosted-account-controls.js

Source: [backend/qa/hosted-account-controls.js](../../../../backend/qa/hosted-account-controls.js)

Runs opted-in account move and account policy checks using its own synthetic hosted accounts; it changes disposable server state.

See [Tests](../../../../docs/TESTING.md) before running it. Hosted Live tests need an explicitly chosen disposable service; local tests must not use an installation containing wanted accounts.
