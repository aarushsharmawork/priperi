# hosted-security-readonly.js

Source: [backend/qa/hosted-security-readonly.js](../../../../backend/qa/hosted-security-readonly.js)

Runs opted-in denial probes on a configured hosted endpoint without a valid user login.

See [Tests](../../../../docs/TESTING.md) before running it. Hosted Live tests need an explicitly chosen disposable service; local tests must not use an installation containing wanted accounts.
