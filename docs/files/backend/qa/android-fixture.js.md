# android-fixture.js

Source: [backend/qa/android-fixture.js](../../../../backend/qa/android-fixture.js)

Starts the local test server, builds the private emulator variant and runs selected Android instrumentation cases.

See [Tests](../../../../docs/TESTING.md) before running it. Hosted Live tests need an explicitly chosen disposable service; local tests must not use an installation containing wanted accounts.
