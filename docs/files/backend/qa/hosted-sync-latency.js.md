# hosted-sync-latency.js

Source: [backend/qa/hosted-sync-latency.js](../../../../backend/qa/hosted-sync-latency.js)

Creates opted-in synthetic hosted accounts and measures bounded send/sync timings, then attempts cleanup.

See [Tests](../../../../docs/TESTING.md) before running it. Hosted Live tests need an explicitly chosen disposable service; local tests must not use an installation containing wanted accounts.
