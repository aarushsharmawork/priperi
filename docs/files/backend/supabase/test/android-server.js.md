# android-server.js

Source: [backend/supabase/test/android-server.js](../../../../../backend/supabase/test/android-server.js)

Provides fake managed Auth and relay behavior backed by disposable SQL for emulator tests.

See [Tests](../../../../../docs/TESTING.md) before running it. Hosted Live tests need an explicitly chosen disposable service; local tests must not use an installation containing wanted accounts.
