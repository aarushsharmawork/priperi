# database.js

Source: [backend/supabase/test/database.js](../../../../../backend/supabase/test/database.js)

Creates a disposable PGlite database, synthetic Auth tables and selected migrations for backend tests.

See [Tests](../../../../../docs/TESTING.md) before running it. Hosted Live tests need an explicitly chosen disposable service; local tests must not use an installation containing wanted accounts.
