Contains the standard BIP-39 English word list used to encode transfer/recovery entropy. It contains no saved recovery phrase.

This file is compiled or packaged by the Android build. See [Build](../../../../../../../../docs/BUILD.md). It has no private value to paste unless its configuration note says otherwise.
